## 关于本项目

HuijiComServe 是 anyingiit 的一个已归档的项目脚手架。仓库唯一的一次提交只添加了 GitHub 治理和模板文件——issue 模板、[CODEOWNERS](.github/CODEOWNERS)、[dependabot](.github/dependabot.yml) 与 [release](.github/release.yml) 配置、一个 CI 工作流起始模板、一份 [pre-commit](.pre-commit-config.yaml) 配置，以及许可证、贡献指南、行为准则、安全策略和更新日志文档——没有任何应用程序源代码、构建清单或入口点。

这里没有需要构建或运行的应用程序；具体含义见下方的[前置条件](#前置条件)和[使用方法](#使用方法)。

## 开始使用

### 前置条件

- [Git](https://git-scm.com/)，用于克隆本仓库。
- [pre-commit](https://pre-commit.com/)，仅当你打算运行 [`.pre-commit-config.yaml`](.pre-commit-config.yaml) 中声明的钩子时才需要。

### 安装

没有任何软件包需要构建或安装——本仓库只是脚手架，不是软件。获取本地副本：

```sh
git clone https://github.com/anyingiit/huijiComServe.git
```

如果你打算使用 [pre-commit](https://pre-commit.com/) 钩子，克隆后运行 `pre-commit install`。

## 使用方法

没有任何东西可以运行。仓库中的任何位置都没有声明清单、脚本或入口点——[`.github/`](.github) 目录（issue 模板、CODEOWNERS、dependabot、release 和 CI 配置）是唯一的内容，它的存在是为了支撑未来的工作，而不是被执行。

## 贡献
